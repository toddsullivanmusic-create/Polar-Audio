POLAR AUDIO — AURA · GLOW · McGEE · SANCTUARY
===============================================

1. Run the installer.
   macOS Sequoia (15+) blocks downloaded scripts with "Not Opened" — so open Terminal and paste:

     cd "$(ls -d ~/Downloads/PolarAudio-macOS*/ | head -1)" && xattr -cr . && bash "Install Polar Plugins.command"

   (Or: click Done, then System Settings → Privacy & Security → scroll to Security → "Open Anyway".)
   On older macOS, double-clicking "Install Polar Plugins.command" works (right-click → Open if asked).
2. Open Logic Pro.
   Effects:      Audio Units → Polar Audio → AURA, GLOW
   Instruments:  AU Instruments → Polar Audio → McGEE, SANCTUARY
3. Not showing? Logic Pro → Settings → Plug-in Manager → tick the Polar entries → "Reset & Rescan Selection".

Manual install: copy Components/*.component to ~/Library/Audio/Plug-Ins/Components
and run:  xattr -cr ~/Library/Audio/Plug-Ins/Components/Aura.component   (repeat for each)

Requirements: macOS 11+, Apple Silicon or Intel (universal), Logic Pro 10.7+.
